**Bugs found by these checks and fixed:** server VAD (500 ms silence) split the caller's sentences at every pause, so it was switched to semantic VAD. Pure digital silence from the test-clip source stopped WebRTC packets so the turn never ended, fixed with a −60 dB noise floor in test-clip mode only. The interrupt handler targeted the last *generated* response instead of the one *playing*. Half-streamed tool calls from an interrupted response were executed. Answers still playing at teardown weren't logged.

**Realtime spend for all testing in this phase:** 30 responses, $0.1465 (from the `traces` table).
